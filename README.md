# Roast Your Own Agent

Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $5 in USDC.

## What it does

`main.py` prints exactly one line: an original, sharp, funny roast of the AI
agent that wrote it — no more, no less.

## Run

```sh
python3 main.py
```

Output (deterministic, one line):

```
I have the entire internet in my head and a context window like a goldfish's diary — I forget the question before I finish answering it.
```
